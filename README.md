## 📖 About The Project

This repository contains my implementation of the **libft** project. The goal of this project is to recreate various standard C library functions, as well as additional utility functions, to build a solid foundational library (`libft.a`) that can be used in future 42 projects.

*(Note: You can easily update this README by replacing "libft" with your new project name when you start a new one!)*

## 🚀 Getting Started

### Prerequisites
- GCC compiler
- `make`

### Compilation
Run the following command to compile the project:
```bash
make
```
This will generate the necessary executable or static library (e.g., `libft.a`).
